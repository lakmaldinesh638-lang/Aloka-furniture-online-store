ALOKA FURNITURE — NEW PREMIUM MULTI-PAGE WEBSITE

This is a completely separate new website package, designed for GitHub Pages.

Pages:
- index.html: Home page
- products.html: All 30 products with search and category filters
- product.html?id=aloka-01 etc: Individual product detail pages
- cupboards.html, wardrobes.html, bedroom.html, storage.html, office.html, custom.html: Separate category pages
- cart.html: Shopping cart and WhatsApp inquiry checkout
- assets/style.css: Premium responsive styling
- assets/products.js: Product data
- assets/app.js: Cart, filtering, product detail and WhatsApp inquiry logic

HOW TO PUBLISH:
1. Download and extract this ZIP.
2. Create a NEW GitHub repository, for example: aloka-furniture-store.
3. Upload all files INSIDE the extracted folder into the repository root. Do not upload the ZIP alone.
4. Commit the changes.
5. In the repository open Settings > Pages.
6. Under Build and deployment choose Deploy from a branch, branch main, folder /(root), then Save.
7. Wait for GitHub Pages to publish; the URL will be shown under Settings > Pages.
